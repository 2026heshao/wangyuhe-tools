支持哪些系统？+
目前安装包均面向 Windows 10 / 11 的 64 位系统。目标电脑无需预装 Python 等运行环境。
安装包安全吗？会被误报吗？+
程序为作者原创、使用 Inno Setup 正常打包。个别杀软可能对未签名的 EXE 弹窗提示，属常见现象，可放心使用或加入白名单。
FloatPulse 的知识卡片没内容？+
知识卡片数据源为同目录下的「知识库.docx」（仅支持 .docx）。放入你自己的文档后即可显示卡片，程序本身仍正常运行。
PyPacker 是安装包还是源码？+
PyPacker 现已提供独立安装包（PyPacker_set_up1.0.exe），双击即可安装，无需自行配置 Python 环境。若想自定义打包逻辑，源码仍可自由修改。
